# Restored original model source

`Untitled-1.scad` is restored byte for byte from [the original model repository](https://github.com/ahzs645/openscad-playgroundrack/blob/a822f3d96e6991cb67e980dd29771ba64c9ef2d4/Models/Tray%20Scad/Untitled-1.scad).

- Repository: `ahzs645/openscad-playgroundrack`
- Source commit: `a822f3d96e6991cb67e980dd29771ba64c9ef2d4`
- Original path: `Models/Tray Scad/Untitled-1.scad`
- Git blob SHA-1: `04bcafc8c022cf440adf23e28c6a51dc669d03c7`

Commit `6961cb88964b01c11f3fbda015bdc943b7d98639` removed this source while adding a `main.scad` wrapper that still includes it. The Tau fork inherited that incomplete wrapper. This migration restores the original source so the existing entry point can execute without changing its geometry. Existing source comments and any attribution are retained. The original repository’s complete license and dependency notices are preserved byte for byte in `SOURCE_LICENSE.md` (Git blob `0cda52d9f6c6fd8dde2d3403e926bde18a571718`). The source has no individual license header; this migration does not relicense it.

The two original auxiliary drawings are also preserved: `SVG/Asset 1.svg` (blob `175aa99123b409e76644ab45f1c855b50b288626`) and `SVG/Asset 2.svg` (blob `59d1090a8fc04aeff164d06abb49b365cad9b2b8`). They are not imported by the original tube rack but remain available in its source archive.
